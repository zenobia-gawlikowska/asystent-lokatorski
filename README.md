# Asystent Lokatorski

A document routing tool for [Komitet Obrony Praw Lokatorów (KOPL)](https://lokatorzy.info.pl/).

Helps tenants and KOPL staff navigate to the correct legal document template for a given tenancy case — via a tile-based decision wizard that encodes KOPL's procedural knowledge.
